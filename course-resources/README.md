# Course resources

Documents the educator wants the generated course to follow or draw on (requirement CFG07): institutional GenAI policies, existing syllabi, reading lists, example slides or assessments.

- Add files here via the `gather-sources` skill, which also records each file in `config/config.yaml` under `attachments` with a note on how it should be used. Files placed here by hand are ignored until they are recorded there.
- Any readable format works (PDF, Markdown, text, images of documents).
- `example-university-genai-policy.md` is a **fictional** sample policy used by `config/examples/one-day-workshop.yaml`; replace it with your own.
