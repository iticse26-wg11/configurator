# H2 — Two tools, one prompt (homework before Session 3, ~25 min)

*Adapted from the pre-sessional part of "Application of AI to Specific Problem".*

**Policy check:** do not include any real personal data in the prompt; both tools are fine for this non-sensitive task.

Give **ChatGPT (free)** and **GitHub Copilot** (in your editor, via the University licence) the same prompt:

> Outline the data model for a small university course-management app: the main entities, their key fields, and how they relate.

Record:

| | ChatGPT (browser chatbot) | GitHub Copilot (editor assistant) |
|---|---|---|
| Quality and usefulness of the outline | | |
| Differences in what each produced (entities, fields, relationships) | | |
| What could each tool "see" — only my prompt, or my files too? | | |
| Where did my prompt go, and who stores it? (check each tool's data/privacy page) | | |
| Is the underlying model open-source or proprietary? What difference would that make for University data? | | |
| Which would I choose for University coursework under the policy, and why? | | |

Bring two findings you'd share with the class.
