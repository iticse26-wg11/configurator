# W3 — Case cards and evaluation grid (Session 4)

## Case cards (one per group)

**Case 1 — Health-advice chatbot.** A GenAI chatbot on a pharmacy chain's website answers customers' questions about symptoms and over-the-counter medicines. *Users:* the public, including older people and non-native speakers. *Data:* conversations are stored to "improve the service". *Known failure modes:* confident but wrong dosage advice; not recognising emergencies; different answers to the same question.

**Case 2 — Poster generator for a student society.** A society uses an image-generation tool to make event posters, prompting with "in the style of" well-known illustrators. *Users:* society committee; posters seen by all students. *Data:* prompts only; the tool was trained on scraped images. *Known failure modes:* stereotyped depictions of people; styles copied from living artists; text in images garbled.

**Case 3 — AI pre-grading of programming assignments.** A department pilots a GenAI assistant that reads student submissions and drafts a mark and feedback for the tutor to approve. *Users:* tutors; affected: students. *Data:* student code and names sent to a cloud API. *Known failure modes:* marking down unusual-but-correct solutions; feedback that sounds authoritative but misreads the code; tutors approving without reading.
